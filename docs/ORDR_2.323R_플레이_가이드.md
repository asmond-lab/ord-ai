# 원피스 랜덤 디펜스R 2.323[R] 플레이 가이드

분석 대상: `ORDR_S2_2.323[R].w3x`  
작성일: 2026-09-27  
기준: 제공된 맵의 스크립트, 유닛·능력·업그레이드 데이터, 내부 도움말.

이 문서는 **해당 파일을 직접 분석한 플레이 설명서**다. 워크래프트 III에서 한 판을 실행해 검증한 실전 공략이나 캐릭터 티어표는 아니다. 아래의 **규칙**은 정적 코드·데이터 근거, **운영 제안**은 그 규칙에서 도출한 판단이다. 툴팁만 확인한 수치는 따로 표시했다. 상세 발췌와 파일 지문은 [분석 근거](ORDR_2.323R_분석_근거.md)에 있다.

## 1. 어떤 게임인가

최대 4명의 플레이어가 각자의 라인을 방어하면서 공용 스토리를 진행하는 유닛 조합 디펜스다. 일반 RTS처럼 일꾼을 늘려 금광을 캐고 병영에서 군대를 생산하는 게임이 아니다.

기본 순환은 다음과 같다.

**위습 획득 → 무작위 유닛 소환 → 재료를 조합해 상위 유닛 확보 → 라인·보스·스토리 처리 → 보상으로 다음 조합 완성**

플레이 중 동시에 해결해야 하는 문제는 세 가지다.

| 전장 | 해야 할 일 | 실패 위험 |
|---|---|---|
| 내 라인 | 계속 쌓이는 일반 몬스터를 처리 | 유닛 수 제한과 데스 카운트 |
| 라운드 보스 | 제한시간 안에 보스를 처치 | 해당 플레이어 탈락 |
| 공용 스토리 | 스토리 건물을 차례로 파괴 | 어려움 이상에서 지정 진행도를 못 맞추면 전원 패배 |

따라서 **높은 등급 유닛 한 기를 만드는 것만으로는 충분하지 않다.** 여러 적을 지우는 능력, 단일 보스를 잡는 능력, 적을 묶어 두는 능력, 스토리 진행 능력을 함께 갖춰야 한다.

## 2. 첫 판은 이렇게 시작한다

### 방 설정과 초기 준비

1. 리포지드에서 해당 맵으로 사용자 지정 게임을 연다. 혼자서도 시작할 수 있으며 플레이어용 처리 슬롯은 4개다.
2. 첫 판은 **쉬움 또는 보통, 추가 모드 없이** 시작하는 것을 권한다. 이는 학습을 위한 제안이지 강제 규칙은 아니다.
3. 시작 지급 처리에는 **50골드, 랜덤위습 5기, 진화체위습 1기**가 있다. 로드 보상 등 추가 지급과는 구분한다.
4. 랜덤위습을 `'흔함' 유닛 랜덤획득`이라고 표시된 구역으로 이동시켜 병력을 만든다. 위습은 사용하면 소모된다.
5. 나온 유닛을 자기 라인에 배치해 공격시킨다. 조합 재료를 찾는 동안에도 라인이 비어 있지 않게 한다.
6. 진화체위습도 사용한다. 해당 처리는 안흔함 1기를 무작위로 만들고, 라인 적 처치 카운트가 **152**에 도달하면 활성화되는 진화체를 준비한다. 화면의 `0 / 152` 진행도를 확인한다. 처음 검게 표시되거나 움직이지 않는 것을 바로 오류로 판단하지 않는다.

최초 준비 타이머는 21초다. **2라운드부터는 신세계를 포함해 매 라운드 시작 시 활성 플레이어에게 랜덤위습 2기**를 지급하는 코드가 있다. 1라운드의 시작 위습 5기와 혼동하지 않는다. [S1]

### 로그인과 오프라인 연습

- 계정 기록을 불러오려면 좌측 상단 `로그인` 안내를 확인한다. 게임은 **9라운드까지만 로드 가능**하다고 알린다.
- 로그인 전에 `-오프라인모드`를 입력하면 클리어 횟수 50회 보정을 받는 연습 경로가 있다. **이 경우 세이브할 수 없다.**
- 싱글모드에서는 로그인할 수 없다는 별도 검사도 있다.
- 이 분석에서는 외부 로그인·세이브 서버의 현재 동작을 시험하지 않았다. [S2]

## 3. 실제 조작: 무엇을 선택하고 눌러야 하나

기본 이동·공격·홀드는 워크래프트 III 조작을 따른다. 아래 단축키는 맵에 정의된 값이며 사용자 키 설정에 따라 다르게 보일 수 있다.

| 선택 대상 / 상황 | 조작 | 용도 |
|---|---|---|
| 일반 유닛 | 우클릭 이동·공격, `A` 공격, `H` 홀드 | 라인 배치와 대상 지정 |
| 조합 가능한 유닛 | 조합 버튼의 설명 확인 후 `Z`, `X` 등 해당 키 | 필요한 재료를 소비해 상위 유닛 생성 |
| 특별 이하 유닛 | `V` 유닛 모으기 | 자신 소유의 같은 종류 유닛을 사용 지점으로 모으고 홀드 |
| 해당 기능이 있는 유닛 | `G` 창고로 이동 | 툴팁상 희귀까지 창고 이동 가능 |
| 기록지침 | `F` | 기록지침 UI 열기·닫기 |
| 열린 기록지침 | `Esc` | UI 닫기 |
| 기록지침 | `W` 아이템 발굴, `E` 유니크 발굴 | 획득한 발굴 스택 사용 |
| 기록지침 | `D` 발굴 스택 교환 | 일반 발굴 4회를 유니크 발굴 1회로 전환 |
| 맵 도움말 | `F9` | 배포처와 채팅 명령어 확인 |

같은 키라도 **선택한 유닛·건물에 따라 기능이 다르다.** 예를 들어 일반 유닛의 `A` 공격과 도움소의 `A` 충격, 도박소의 `A` 하급 유닛도박을 혼동하지 않는다.

### 위습과 창고

- 랜덤위습은 일반 소환뿐 아니라 **목재 도박**, **도움소 마나 회복**에도 소비할 수 있다.
- 흔함선택위습은 필요한 흔함을 보충하는 자원이고, 안흔함·특별·희귀·전설 위습에는 각각 별도의 획득 구역이 있다.
- `흔함-자동꺼내기`를 끄면 흔함이 창고로 들어가고, 켜면 창고로 들어가지 않는다. “위습을 썼는데 유닛이 안 보인다”면 창고와 이 설정부터 확인한다.
- 맵의 `스토리존 입장` 표식을 통해 병력을 보내고, `스토리존 퇴장`으로 돌려보낸다. **라인 병력을 전부 스토리에 보내지 않는 것**이 초보 운영의 기본이다. [S3]

## 4. 조합을 이해하는 법

### 등급은 단순한 한 줄 사다리가 아니다

일반적인 재료 성장 흐름은 **흔함 → 안흔함·특별 → 희귀 → 전설·히든 → 최상위 조합**이다. 다만 모든 캐릭터가 각 단계를 한 번씩 거치는 것은 아니다.

- 흔함 2기로 안흔함을 만드는 조합도 있고, 같은 흔함 3기로 특별을 만드는 조합도 있다.
- 같은 캐릭터라도 등급이 다르면 별개의 재료다.
- 히든·변화·왜곡·초월·불멸·영원·제한·신비는 서로 다른 조건의 갈래다. 이름만 보고 무조건 상하 관계로 정렬하면 안 된다.
- 조합에 사용한 전투 유닛은 재료로 소모된다. 핵심 스턴·방어력 감소 유닛을 재료로 쓰면 완성 직전보다 라인이 약해질 수도 있다.

### 이 파일에서 확인한 조합 예시

| 결과 | 재료 | 확인된 조합 키 |
|---|---|---|
| 에이스 안흔함 | 루피 흔함 + 해군 총병 흔함 | 루피의 `Z` |
| 로빈 안흔함 | 나미 흔함 + 상디 흔함 | 나미의 `Z` |
| 브룩 안흔함 | 조로 흔함 + 쵸파 흔함 | 조로의 `Z` |
| 페로나 안흔함 | 버기 흔함 + 나미 흔함 | 버기의 `Z` |
| 블루노 안흔함 | 해군 총병 흔함 2기 | 총병의 `Z` |
| 루피 기어세컨드 특별 | 루피 흔함 3기 | 루피의 `X` |
| 나미 크리마텍트 특별 | 나미 흔함 3기 | 나미의 `X` |
| 로빈 오하라 특별 | 로빈 안흔함 2기 + 쵸파 흔함 | 해당 조합 버튼 `Z` |
| 루피 기어서드 희귀 | 기어세컨드 특별 + 봉쿠레 특별 + 에넬 특별 | 해당 조합 버튼 `Z` |

위 표는 전 조합표가 아니라 **재료 읽는 법을 익히기 위한 실제 예시**다. 능력 툴팁을 추출했고, 에이스·로빈 등의 기본 조합은 스크립트 재료 테이블과도 대조했다. [S4]

일부 상위 조합은 채팅 명령도 제공한다. 예를 들어 스크립트에는 `검호조합`, `해적왕이될사나이`가 등록되어 있다. **문구만 입력한다고 무료로 생성되는 것은 아니며**, 조합 재료와 추가 조건 검사를 통과해야 한다.

### 초월위습의 이름에 주의

이 파일에서 초월위습을 사용하는 `w2v`는 **희귀 레일리와 해적선**을 생성한다. 곧바로 원하는 완성 초월 유닛을 주는 선택권이 아니다. 펑크해저드 보상으로 초월위습을 받았다고 최상위 조합이 끝났다고 생각하면 안 된다. [S5]

### 실용적인 조합 계획

운영 제안:

1. 당장 만들 수 있는 유닛 중 라인과 스토리를 버텨 줄 중간 전력을 먼저 만든다.
2. 나온 희귀·전설과 겹치는 재료를 기준으로 최종 후보를 좁힌다.
3. 흔함선택위습은 필요한 조합의 마지막 재료를 채우는 데 우선 쓴다.
4. 최상위 딜러의 재료와 스턴·감속·방어력 감소용 재료를 구분한다.
5. 긴 최종 조합을 위해 현재 라인 방어를 희생하지 않는다.

외부 조합 도우미는 편리하지만 **인게임 2.323[R]의 조합 설명을 우선**한다. 웹 도우미의 키 설정을 게임 단축키로 옮겨 쓰지 않는다.

## 5. 자원: 무엇을 어디에 써야 하나

| 자원 | 주요 역할 | 운영 제안 |
|---|---|---|
| 랜덤위습 | 기본 유닛, 목재 도박, 도움소 마나 | 병력이 부족할 때 전부 목재로 바꾸지 않는다 |
| 선택·등급 위습 | 필요한 흔함 보충 또는 해당 등급 획득 | 조합 병목을 푸는 데 사용 |
| 골드 | 도박, 업그레이드, 상품 구매 | 화면의 실제 비용·재고와 목표 조합을 함께 확인 |
| 목재 | 유닛도박 및 일부 고급 조합·구매 | 최종 재료용 목재까지 도박에 쓰지 않는다 |
| 특성포인트 | 유닛 특성, 도움소 선택위습 제조 등 | “아무 용도 없는 인구수”로 취급하지 않는다 |
| 발굴 스택 | 기록지침의 아이템 획득 | 보상을 받았으면 사용 가능 여부 확인 |
| 베리·계정 기록 | 칭호·누적 보상 등 | 이번 판의 골드·목재와 구분 |

### 목재 도박은 위습을 소비한다

랜덤위습을 목재 도박 구역에 보내면:

- 67% 확률로 목재 1개.
- 실패하면 `현재 라운드 × 75` 골드.

안내문과 실제 `d2s`의 분기가 일치한다. 따라서 이것은 무료 목재 생산이 아니라 **유닛을 뽑을 기회를 자원으로 바꾸는 선택**이다. 도움소 마나 구역도 랜덤위습을 소비하며 `20 + floor(현재 라운드 × 1.5)`, 최대 100 마나를 회복한다. [S6]

### 유닛도박의 기본 상품

비용은 유닛 오브젝트의 명시값, 확률은 해당 상품 툴팁 기준이다. 재고·해금·항법으로 구매 가능 여부나 효과가 달라질 수 있다.

| 상품 | 골드 | 목재 | 기본 설명 |
|---|---:|---:|---|
| 하급 `A` | 200 | 1 | 85% 확률로 흔함~안흔함, 해적선 2% 안내 |
| 중급 `S` | 1,000 | 2 | 70% 확률로 특별, 해적선 4.5% 안내 |
| 고급 `D` | 2,000 | 4 | 70% 확률로 특별~희귀, 희귀 레일리 4% 안내 |
| 목재 구입 | 10,000 | - | 목재 1개로 변환 |

중급·고급 툴팁은 압살롬이 나오지 않는다고 명시한다. 표의 추가 획득 확률을 앞의 성공률과 임의로 더해 전체 성공률로 계산하지 않는다. 모든 도박의 세부 확률식을 시뮬레이션한 문서는 아니다. [S7]

### 판매·업그레이드·아이템

- 흔함 판매는 툴팁상 1포인트씩 누적하고 3포인트에 랜덤위습 1개를 돌려준다. 추가 목재 확률도 있다.
- 안흔함 판매도 확률형 회수다. **조합 재료 판매는 원상복구가 보장되지 않는다.**
- 등급별 업그레이드와 캐릭터별 예외가 존재한다. 주력 유닛에 적용되는 업그레이드 설명을 읽고 투자한다.
- 기록지침 일반 발굴은 툴팁상 노멀 90%, 유니크 10%이며 미션에서 발굴 스택을 얻는다. 발굴과 보물 탐색은 별개 기능이다.
- 기록지침의 `[탐색]`은 클릭한 지점 주변의 보물상자를 찾는다. 툴팁상 10라운드마다 창고·조합식 구역을 제외한 곳에 `플레이어 수 + 4`개의 상자가 재생성된다. [S7]

## 6. 난이도와 정확한 승패 조건

### 난이도별 핵심 표

| 난이도 | 라인 유닛 수 한계 | 35라운드 종료 전 필요한 스토리 | 기본 클리어 지점 |
|---|---:|---|---|
| 쉬움 | 100 | 해당 난이도의 강제 검사 없음 | 40라운드 종료, 안내상 41라운드 진입 |
| 보통 | 100 | 해당 난이도의 강제 검사 없음 | 50라운드 센고쿠 처리 후 종료 |
| 어려움 | 80 | 9. 어인섬 | 65라운드 종료 |
| 지옥 | 70 | 11. 드레스로자 | 65라운드 종료 |
| 신 | 70 → **41라운드부터 55** | 12. 홀케이크섬 | 65라운드 종료 |
| 악몽 | 70 → **41라운드부터 50** | 13. 와노쿠니 | 65라운드 종료 |

쉬움·보통에서도 스토리 보상은 성장에 유용하다. “35라운드 강제 검사가 없다”는 말은 “스토리를 안 해도 운영상 손해가 없다”는 뜻이 아니다. [S8]

### 라인 패배: 한계 이상을 방치하면 안 된다

- 카운트는 **아군 수가 아니라 자기 라인의 적 수**다. 보스 등 카운트 대상도 포함된다.
- 초기 데스 카운트는 20이다. 한계 이상인 상태에서 검사될 때마다 감소하고 0 이하가 되면 탈락한다.
- 검사는 몬스터 생성 과정과 0.5초 타이머 등에 연결된다. **20라운드나 20번의 별도 위기를 허용한다는 뜻이 아니다.**
- **50라운드 종료 후 신세계 전환 처리에서 데스 카운트를 0으로 바꾼다.** 이후에는 한계 이상이 검사되면 유예 없이 탈락할 수 있다.
- 40라운드까지는 한계 15마리 전, 그 이후는 10마리 전부터 경고한다. 경고가 뜰 때 조합창만 보지 말고 라인에 개입한다. [S9]

### 보스와 라운드 시간

| 구간 | 일반 라운드 | 보스 라운드 |
|---|---|---|
| 1~50 | 기본 35초, 기본 몹 35기 | 10·20·30·40·50라운드, 60초 |
| 51~65 신세계 | 기본 32초, 기본 몹 35기 및 별도 광폭화 몹 | 55·60·65라운드도 32초, 기본 몹과 보스가 함께 나옴 |

어려움 이상은 50라운드 종료 후 **70초 출항 준비**를 거쳐 신세계로 넘어간다. [S10]

보스 순서는 **10 아론 → 20 크로커다일 → 30 에넬 → 40 루치 → 50 센고쿠 → 55 도플라밍고 → 60 빅 맘 → 65 카이도**다. 마지막 보스는 내부 ID `o02B`로 확인했다.

보스가 남은 채 라운드가 끝나면 해당 플레이어를 탈락시키는 공통 코드가 있다. 어려움 이상은 65라운드 종료 처리로 승리하되, 그 전에 최종 보스 생존 검사가 먼저 실행된다. **보스를 때려 죽이는 것과 승리 화면이 뜨는 시점은 같지 않을 수 있다.**

**쉬움의 불일치:** 난이도 설명은 “보스를 죽이지 못해도 패배하지 않는다”고 하지만, 추출한 공통 보스 패배 처리에는 쉬움 예외가 없다. 실전 동작은 확인하지 못했다. 따라서 이 문서에서는 **쉬움에서도 제한시간 안에 보스를 잡는 방향으로 플레이**하도록 안내한다. [S11]

### 추가 모드

- 지옥 이상에서 추가 모드를 적용하는 분기가 있다.
- **변질:** 안내상 상위 테크 유닛의 30%가 조합 불가능해진다. 고정된 최종 조합 하나만 생각하고 시작하면 계획이 막힐 수 있다.
- **이세계:** 이세계 유닛과 이세계 도박을 활성화한다.
- 연구소 모드는 선택 UI 흔적이 있지만, 이번 분석에서 실제 적용 효과까지 확정하지 못했다.
- 다른 버전의 “초고속 모드” 설명을 이 파일의 확정 규칙으로 넣지 않았다. [S8]

## 7. 스토리는 팀 전체의 성장 엔진이다

스토리 순서:

**로그타운 → 알라바스타 → 하늘섬 → 워터세븐 → 스릴러바크 → 샤봉디 → 임펠다운 → 마린포드 → 어인섬 → 펑크해저드 → 드레스로자 → 홀케이크섬 → 와노쿠니 → 에그헤드**

스토리를 밀면 활성 플레이어들에게 골드·목재·위습 등이 지급되고, 일부 구간에는 MVP나 기여도 추가 보상이 붙는다. 그래서 “내 라인만 버티기”보다 **라인을 유지하면서 스토리를 앞당겨 보상을 다시 전력으로 바꾸는 운영**이 중요하다.

확인한 기본 보상 사례:

| 완료한 스토리 | 전원 기본 보상 사례 |
|---|---|
| 로그타운 | 180골드 + 흔함선택위습 3개 |
| 마린포드 | 8,000골드 + 목재 4개 + 희귀위습 3개 |
| 펑크해저드 | 10,000골드 + 목재 4개 + 초월위습 1개 + 랜덤위습 2개 |
| 홀케이크섬 | 10,000골드 + 목재 3개 + 특성포인트 1개 + 흔함선택위습 3개 + 특별위습 2개 |

이는 추가 기여도 보상을 제외한 사례이며, 총수급 계산표는 아니다. [S12]

어려움 이상에서는 35라운드 종료 전 목표 스토리를 맞춰야 한다. 이는 개인 미션과 달리 **팀 전체 패배 조건**이다.

신·악몽에서는 와노쿠니 완료 후 **120초 뒤 에그헤드 등장**, 등장 후 **240초 격파 제한**이 있다. 제한시간 만료 시 전체 플레이어를 탈락시키는 처리가 있으므로 35라운드 목표를 달성했다고 스토리 담당을 완전히 해제하면 안 된다. [S13]

## 8. 21라운드의 중요한 선택: 항법

**이 버전은 게임 시작 시 항법을 고르는 구조가 아니다.**

- 21라운드부터 기록지침에서 선택 가능.
- 25라운드 시작 전까지 선택해야 한다.
- 24라운드 종료 시 미선택이면 **연합세력 :: 일석이조**가 자동 선택된다.

| 항법 | 기본 성격 | 유의점 |
|---|---|---|
| 연합세력 | 전설·히든 이상 조합 시 랜덤위습 수급 | 일석이조는 추가 지급 및 기존 조건 충족분 소급 지급 |
| 패왕의길 | 전설 레오 지원 | 기본 설명부터 최상위 조합을 1기로 제한 |
| 도박광 | 희귀 리롤 횟수 등 도박 보강 | 하위 선택에 따라 도박 상품 제한·효과가 달라짐 |
| 최고의도움 | 도움소 마나 회복 강화 | 도움소 스킬 활용을 요구 |
| 랜덤선택 | 항법을 무작위로 선택 | 원하지 않는 제한이 붙을 수 있음 |

각 항법의 하위 선택에는 기본효과를 끄는 페널티도 있다. **상위 항법 이름만 읽지 말고 노드 효과와 빨간 페널티를 함께 읽는다.**

초보에게는 연합세력·일석이조가 이해하기 쉬운 출발점이라는 것이 이 문서의 운영 제안이다. 최적 빌드임을 실전으로 검증했다는 뜻은 아니다. [S14]

## 9. 개인 미션과 도움소를 어떻게 쓰나

### 개인 미션

스토리와 별도로 미션 건물에서 적을 자기 라인에 소환해 잡는 임무가 있다. 아래는 현재 미션 상품의 툴팁 기준이다.

| 미션 | 제한시간 | 주요 보상 |
|---|---:|---|
| 깅 | 60초 | 1,500골드 + 목재 2 |
| 클리크 | 60초 | 3,000골드 + 목재 4 |
| 모리아 | 60초 | 3,000골드 + 목재 3 + 특별위습 1 |
| 피카 | 60초 | 3,000골드 + 목재 3 + 특성포인트 1 |
| 거프 | 60초 | 랜덤위습 1 + 아이템 발굴 1회 |
| 와포루 | 60초, 21~30라운드 | 안흔함위습 1 + 목재 1 |
| 바제스 | 60초, 31~40라운드 | 3,000골드 + 목재 3 + 선택위습 1 |

한 번만 수행할 수 있는 미션이며, 해금 시점과 신세계 전 제한 등 상품별 조건이 있다. 바제스는 높은 회복률과 205만 이상의 피해 요구를 경고한다.

운영 제안: **평소 라인을 여유 있게 지우고, 다음 보스와 겹치지 않을 때** 도전한다. 라인이 이미 쌓이는데 보상만 보고 추가 적을 부르면 위험하다.

맵에는 구형 미션 설명도 남아 있다. 예전 스모커·와포루 설명의 “실패 시 2라운드 위습 미지급”이나 “스토리 450만 피해”를 이 버전의 모든 현재 미션에 적용하지 않았다. [S15]

### 도움소는 직접 사용하는 비상 수단

도움소를 선택하면 공격·군중제어·보조 능력을 쓸 수 있다. 일반 상태 툴팁의 예:

| 키 | 스킬 | 용도 |
|---|---|---|
| `Q` | 폭우 | 초반 범위 피해 |
| `W` | 낙뢰 | 단일 피해와 스턴 |
| `A` | 충격 | 범위 스턴 |
| `Z` | 흡수 | 일반 라인 몬스터 하나 제거, 보스용 아님 |
| `F` | 버스터콜 | 큰 고정 피해, 마나·쿨타임 확인 |
| `S` | 해루석 | 단일 대상 제압과 피해 |
| `V` | 선택위습 제조 | 특성포인트 1과 마나를 써 선택위습 획득 |

항법에 따라 강화되거나 사용 제한이 달라진다. **보스 종료 직전, 유닛 수 경고, 스토리 마감**에 쓸 수 있도록 마나와 쿨타임을 의식하는 것이 좋다. 모든 스킬을 자동으로 사용해 준다고 가정하지 않는다. [S7]

## 10. 조합의 전투 역할을 맞추는 법

아래는 맵의 스킬 유형을 바탕으로 한 운영 제안이며 특정 캐릭터의 성능 순위가 아니다.

| 역할 | 필요한 이유 | 부족할 때 보이는 증상 |
|---|---|---|
| 범위 딜·라인 정리 | 매 라운드 들어오는 여러 적을 처리 | 보스는 잡는데 몹 수가 계속 증가 |
| 단일 딜·보스 처리 | 높은 체력의 한 대상을 시간 안에 제거 | 일반몹은 잘 지우는데 보스 시간 초과 |
| 스턴·감속 | 적이 딜 구역에 머무르는 시간 확보 | 적이 흩어져 범위 공격 효율이 떨어짐 |
| 방어력 감소 | 물리 공격·물리 스킬 효율 보조 | 물리 주력의 피해가 후반에 답답해짐 |
| 마법방어 감소·마법 피해 증폭 | 마법 피해 중심 조합 보조 | 마법 주력이 있어도 처리 속도가 안 나옴 |
| 공격속도·기타 버프 | 기본 공격 및 공격 시 발동 스킬 보조 | 주력 스킬 발동과 공격 빈도가 부족 |
| 스토리 담당 | 공동 성장 보상과 진행 마감 확보 | 라인은 버티지만 스토리 마감에 실패 |

캐릭터의 기본 공격 유형만 보고 물리·마법 역할을 결정하지 않는다. 툴팁에는 물리·마법·고정·폭발형 피해가 섞여 있고, 일반몹과 보스·스토리에 다른 배율을 쓰는 스킬도 있다.

또한 모든 오라·버프가 중첩된다고 가정하면 안 된다. 실제 툴팁에도 같은 종류의 효과끼리 중복 불가라는 설명이 있다. 초보 단계에서는 정밀 계산보다 **빠진 역할을 채우는 것**부터 시작한다.

## 11. 한 판의 운영 순서

### 1~10라운드: 조작과 첫 전력

- 시작 위습을 사용하고 조합 버튼과 창고 위치를 익힌다.
- 첫 특별·희귀와 진화체 성장을 이용해 라인을 안정시킨다.
- 스토리에 일부 병력을 보내 첫 보상을 당긴다.
- 로그인할 계획이면 9라운드를 넘기지 않는다.
- 10라운드 아론을 앞두고 단일 화력과 도움소 마나를 확인한다.

### 11~20라운드: 첫 중상위 전력과 수급

- 나온 재료에서 전설·히든 후보를 정한다.
- 스토리 보상을 조합으로 연결한다.
- 여유가 있으면 열린 개인 미션과 탐색을 수행한다.
- 도박 결과가 나쁘다고 라인 방어 자원까지 계속 투입하지 않는다.

### 21~35라운드: 항법과 스토리 마감

- 21라운드에 항법을 읽고 25라운드 전에 고른다.
- 최종 후보의 재료뿐 아니라 스턴·감속·방어 감소를 확보한다.
- 팀에서는 누가 라인, 스토리, 추가 목표를 맡을지 조정한다.
- 어려움 이상은 **35라운드 종료 전 스토리 목표 달성**이 우선이다.

### 36~50라운드: 신세계 준비

- 신·악몽은 41라운드 유닛 수 한계 감소에 대비한다.
- 상위 조합을 만들며 소비한 보조 유닛의 빈자리를 복구한다.
- 업그레이드, 기록지침 아이템, 도움소 운용을 점검한다.
- 보통은 50라운드 센고쿠가 마지막 관문이다.

### 51~65라운드: 라인과 보스를 동시에

- 라운드 시간이 32초로 짧아지고 유닛 수 유예가 사라진다.
- 55·60·65라운드는 보스와 일반몹을 함께 처리한다.
- 조합을 새로 설계하느라 시간을 쓰기보다 배치·대상 지정·도움소 사용에 집중한다.
- 신·악몽은 에그헤드 타이머도 놓치지 않는다.

## 12. 자주 막히는 상황

| 상황 | 먼저 확인할 것 |
|---|---|
| 조합이 안 됨 | 같은 캐릭터라도 등급이 맞는가, 재료 수량·목재·추가 조건이 맞는가, 변질로 막혔는가 |
| 유닛을 뽑았는데 없음 | 창고와 흔함 자동꺼내기 설정 |
| 최상위를 만들었는데 더 약해짐 | 재료로 소모된 스턴·방깎·보조 전력이 있었는가 |
| 보스는 잡는데 패배 | 라인 수 한계 또는 팀 스토리 마감 |

| 신세계에서 한 번에 탈락 | 데스 카운트가 0으로 바뀐 뒤 한계 도달 |

| 세이브가 안 됨 | 로그인 상태, 싱글·오프라인 모드 여부 |

### 외부 자료의 역할

- 공식 배포처는 맵 자체가 [ORDR.PE.KR](https://ordr.pe.kr/)로 안내한다.
- [WC3Maps의 동일 파일명·버전 페이지](https://wc3maps.com/map/459623/R_2.323R)와 [2.323 최신맵 공지](https://gall.dcinside.com/mgallery/board/view/?id=ordc1&no=266820)는 버전 교차 확인에 사용했다.
- [조합 도우미](https://ordr.kr/)와 [패치노트](https://ordr.kr/patch-notes)는 보조 자료다. 웹이 다른 버전으로 갱신되면 이 파일과 달라질 수 있다.

핵심 숫자와 진행 조건은 외부 구버전 공략보다 **제공된 맵 파일**을 우선했다.

### 무엇을 검증했고, 무엇은 검증하지 않았나

- 내부 파일 복호화·압축 해제, 크기·체크섬 일치, 오브젝트 데이터 파싱을 확인했다.
- 주요 진행·패배·승리 트리거와 호출 연결, 난이도 분기, 실제 유닛 ID와 표시명을 대조했다.
- 원본 맵은 수정하지 않았다.
- **워크래프트 III에서 실제 맵 로드, 클리어, 멀티플레이, 로그인·세이브는 실행 검증하지 않았다.**
- 전 캐릭터의 스킬 실행식, 모든 조합의 추가 조건, 확률 분포, 최적 빌드·성능 순위는 전수 검증하지 않았다.
- 문서만 작성한 작업이므로 애플리케이션 빌드·LSP 진단·기존 테스트 실행은 적용 대상이 없다. 문서의 근거 대조와 참조 파일 점검을 수행했다.

첫 판에서 기억할 것은 다섯 가지다. **위습을 병력으로 바꾸기, 라인을 비우지 않기, 스토리 보상을 당기기, 21~24라운드에 항법 고르기, 보스·유닛 수·스토리 마감을 함께 보기.**
