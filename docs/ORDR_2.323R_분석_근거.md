# ORDR 2.323[R] 분석 근거

이 문서는 플레이 가이드의 재검증을 위한 데이터 발췌다. 실제 게임 실행 결과가 아니라 제공된 맵의 정적 분석 결과다.

## 파일 식별과 추출

- 원본: `ORDR_S2_2.323[R].w3x`
- 크기: 119,514,351 bytes
- SHA-256: `eac74a90a967473196c84446b880387857f50a828083c0e1b5fc02b325663535`
- 내부 표시명: 원피스랜덤디펜스R 2.323[R] (WTS 2352).
- MPQ 시작 위치: 2048 bytes. 보호용 중복 해시·유효하지 않은 인덱스와 실제 섹터 구조에 맞지 않는 플래그가 있어, 유효 블록을 선택하고 메모리에서 섹터 단위로 복호화·압축 해제했다. 원본 맵을 수정하지 않았다.
- zlib 압축 해제의 체크섬 검사와 블록의 비압축 크기 일치를 확인했다.
- JASS는 UTF-8로 정상 해석된다. WTS에는 UTF-8 대체문자 5개가 발생하므로 해당 문자는 근거로 사용하지 않는다.
- 추출문은 `../.omo/map-analysis/`에 보존했다. 각 파일은 1800줄 단위이며 마지막 조각만 더 짧다. 원문 줄 번호 = `(part 번호 - 1) × 1800 + 조각 안 줄 번호`.
- JASS 86,357줄, WTS 73,783줄 / 11,082개 문자열. 유닛 오브젝트 1,519개, 능력 1,680개, 업그레이드 110개를 파싱했다. 이 개수에는 더미·이펙트·기본 오브젝트 변경이 포함되므로 플레이 가능한 캐릭터 수가 아니다.

## 해석 시 주의점

- 초월위습 `e01A`는 곧바로 완성 초월 캐릭터를 주는 것이 아니다. `w2v`가 `h05X`와 `h060`을 생성한다 (`war3map.j.part036.txt:845-870`).
- 65라운드 보스 ID는 `$6f303242` = `o02B`이며, `o00B`가 아니다. 해당 유닛 이름은 카이도다 (`war3map.j.part014.txt:1402`).
- 신세계 진입 함수 `HSs`가 데스 카운트 `Es[]`를 0으로 바꾼다 (`war3map.j.part009.txt:856-900`). 초기 20을 게임 전체 유예로 설명하면 안 된다.
- 쉬움의 보스 면제 안내와 공통 패배 검사 `BUs`가 충돌한다. 실제 플레이 검증 없이 쉬움 보스를 무시해도 된다고 확정할 수 없다.
- 외부 구버전 공략의 75라운드, 시작 시 항법 선택 등을 이 버전 규칙으로 전용하지 않았다.
